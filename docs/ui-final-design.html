设计原则

  • 克制的颜色使用，主色仅用于关键操作
  • 浅蓝调色，高级感，不用毛玻璃
  • 精致的阴影层次，不用渐变
  • 微妙的边框细节，1px 边框
  • 大量留白，呼吸感强
  • 等宽数字，数据对齐
  • 圆角 8-12px，柔和不刺眼
  • 响应式布局，适配多端

高级感技巧

  • 不用毛玻璃，用纯色背景
  • 不用渐变，用微妙的色差
  • 阴影要轻，4px 以内
  • 边框要细，1px 足够
  • hover 时微动，translateY(-2px)
  • 过渡要顺滑，cubic-bezier
  • 图标要精致，线性风格
  • 字体要现代，Inter 首选
