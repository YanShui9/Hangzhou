- **入口与初始化**：`main.js` 作为应用入口，挂载 Vue 实例并引入 ElementUI 组件库及全局样式。
- **路由守卫机制**：`permission.js` 实现全局前置守卫，通过检查 Vuex 中的 Token 和用户信息状态，拦截未授权访问并处理动态用户信息加载。
- **权限校验逻辑**：采用基于 `meta.roles` 的 RBAC 模型，在路由跳转时比对用户角色类型（`roleType`），无权限则重定向至首页。
- **API 通信层**：`api/` 目录下按业务域（auth, user）组织接口，统一通过 `utils/request.js` 封装的 Axios 实例发起请求，该实例内置了 Bearer Token 自动注入、全局错误提示及 401 自动登出逻辑。
